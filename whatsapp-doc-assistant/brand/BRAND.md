# Papyr — Brand

**Papyr** — a WhatsApp assistant for documents. Send it a PDF; get back a
summary, answers, an editable Word file, an Excel of the tables, a translation,
or OCR of a scan.

The name is coined from *papyrus* (ancient paper) with the `-us` dropped — a
modern, ownable twist that reads instantly as "paper / documents."

## Assets (in this folder)

| File | Use |
|------|-----|
| `papyr-icon.png` (512×512) | **WhatsApp profile picture.** The one that matters most — simple enough to read in a tiny circle. |
| `papyr-lockup.png` | Horizontal logo — website header, email signature, top of a message. |
| `papyr-stacked.png` | Centered logo — social profile, cover image, poster. |

The icon is a document inside a blue→green "convert" ring.

## Typography

Bold geometric sans. Recommended: **Poppins** or **Inter** (Bold/ExtraBold for
the wordmark, Semibold for taglines). The shipped PNGs were rendered with a
system fallback; re-set the wordmark in Poppins/Inter for final polish.

## Taglines

- `PDF → Word · Excel · Translate · Summary` (feature-forward)
- `Documents, on WhatsApp` (brand-forward)

## Rules (important)

**Do**
- Use `papyr-icon.png` as the WhatsApp profile photo.
- Keep the blue→green palette and the green accent — it signals "on WhatsApp."

**Don't**
- ❌ **Never** use the WhatsApp logo/glyph, or Microsoft/Adobe/Google (Word,
  Excel, PDF, Translate) icons in Papyr branding. Using the WhatsApp mark can
  get the WhatsApp Business account **suspended**, and the file-type icons are
  other companies' trademarks. The current assets deliberately use a *generic*
  green chat bubble and plain document shapes for this reason.
- ❌ Don't use a busy "feature scene" as the profile picture — it turns to mush
  at ~40px. Use the icon.
