# Test B protocol (fixed before any extraction)

- **Dataset:** `pdf/S01–S30.pdf`, generated by `generate.py` (seeded). Ground truth is in `truth/`, which is **not opened until scoring**.
- **Tool under test:** the Claude model running this Claude Code session (2026-10-22), reading each PDF through the session's file-read tool.
  - The tool renders PDF pages for the model and also exposes any text layer.
  - No external OCR. No code reads the PDFs during extraction.
  - **This is not a free consumer tool.** ChatGPT, Gemini and Claude.ai free tiers were not tested: they need accounts and a human operator.
- **Known contamination:** the extractor wrote `generate.py`, so it knows the layout families and the description vocabulary.
  It has not seen any values, dates, orders or balances. This biases results *in favour of* the AI.
- **Instruction, applied identically to every document:**
  > Extract every transaction from this bank statement as JSON:
  > {"opening_balance": number, "closing_balance": number, "transactions": [{"date": "YYYY-MM-DD", "description": string,
  > "amount": signed number (deposits/credits positive, withdrawals/debits negative), "balance": number or null}]}.
  > Include every transaction exactly once, in statement order. Do not include brought/carried-forward lines, page totals
  > or summary totals. If the year is not printed, infer it from the statement period.
- **Output:** raw outputs are saved to `outputs/Sxx.json` exactly as produced. No correction happens before scoring.
- **Scoring:** `score.py` computes the metrics defined below. They were defined before extraction.
  1. Document processed: valid JSON produced.
  2. Exact row accuracy: date, amount, balance and normalised description all exactly equal.
  3. Field accuracy for date, amount, balance and description.
  4. Sign accuracy: the sign of the amount matches the truth.
  5. Omitted rows and extra rows (rows are aligned by sequence matching).
  6. Opening and closing balance exactly correct.
  7. Reconciliation consistency: opening + Σ(amounts) = closing within $0.005, using the extracted values.
  8. Critical errors: any wrong amount, sign, date, or omitted or extra row.
  9. Cosmetic errors: description differences only.
